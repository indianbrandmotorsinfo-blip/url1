# URL Management Dashboard

A premium, minimal homepage for your personal and work URLs. Click a card to open the link, search instantly, and sign in as the single admin to add, edit or delete links.

React + TypeScript + Material UI · FastAPI · SQLite · Nginx · Docker Compose · GitHub Actions with a Trivy security gate · deploys to an OCI Ubuntu VM at `https://myurls.yashwanthgowdam.in`.
